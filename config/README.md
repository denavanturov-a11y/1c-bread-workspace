# Локальные настройки

Сейчас проект не требует постоянных файлов с логинами или паролями. Коннектор запрашивает
данны доступа 1С в окне при каждом запуске и не сохраняет их.

Если позже появятся локальные настройки, в Git можно добавлять только шаблон без секретов.
Реальные `.env`, токены и ключи игнорируются корневым `.gitignore`.
