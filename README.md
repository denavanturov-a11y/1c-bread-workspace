# 1С-Хлеб

Отдельная рабочая папка проекта автоматизации поступления хлеба в 1С.
Внутри есть веб-прототип, Windows-коннектор к локальной 1С,
контекст для Claude и скрипты первого запуска на Windows.

## Первый запуск на рабочем компьютере

1. Скачайте репозиторий через **Code → Download ZIP**.
2. Распакуйте ZIP в обычную папку на диске, например `C:\Projects\1c-bread-workspace`.
3. Дайте Claude доступ к этой папке и напишите:

   > Прочитай CLAUDE.md, установи всё необходимое для проекта и выполни безопасную проверку. Рабочую базу 1С не изменяй.

4. Если Claude не может запускать команды, дважды щёлкните `Установить.cmd`.

Если Git уже установлен, вместо ZIP можно клонировать репозиторий по ссылке GitHub.

## Безопасность 1С

- Диагностика и сопоставление каталога в `connector/` только читают 1С.
- `connector/test-create-unposted.ps1` — отдельный опасный тест. Он допустим только для
  `C:\Baze_Test_Hleb` и не должен запускаться без явного разрешения.
- Пароли 1С вводятся в окне коннектора и не сохраняются в файлах проекта.
- Реальные GUID и состав тестовой накладной хранятся только в игнорируемом файле
  `connector/business-data.local.json`; репозиторий содержит безопасный шаблон.

## Структура

- `CLAUDE.md` — главные инструкции для Claude.
- `connector/` — Windows-скрипты для OData 1С.
- `web/` — веб-прототип приёма накладных.
- `docs/` — архитектура, статус и план переноса.
- `scripts/` и `tests/` — установка и безопасная проверка.

## Текущий статус

Веб-часть остаётся прототипом. Чтение OData подтверждено. Сценарий одной тестовой непроведённой
накладной подготовлен только для копии базы. Рабочая запись и автоматическое проведение ещё не разрешены.
