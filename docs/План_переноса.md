# План переноса проекта «1С-Хлеб»

Статус: обновлённый дизайн согласован
Дата: 2026-08-17

## Понимание задачи

- Создать отдельный переносимый проект только для «1С-Хлеб».
- Включить Windows-коннектор, веб-прототип и актуальный контекст 1С.
- Добавить структуру для работы Claude: `CLAUDE.md`, контекст, скрипты, тесты и безопасные шаблоны настроек.
- Подготовить проверку Git, Node.js и зависимостей проекта на Windows 10; Claude уже установлен.
- Исключить личные материалы WorkHub, секреты, локальные сборки и выгрузки 1С.
- Хранить проект в приватном GitHub-репозитории; при необходимости скачивать его штатной кнопкой GitHub Download ZIP.

## Допущения

- Целевой компьютер: Windows 10 Lite 22H2 x64.
- Claude уже установлен и имеет доступ к файлам; доступ к командам терминала заранее не подтверждён.
- При отсутствии у Claude доступа к терминалу установка запускается двойным щелчком по `Установить.cmd`.
- Наличие прав администратора и `winget` заранее неизвестно; это проверяет скрипт.
- Авторизация в GitHub и 1С выполняется вручную на рабочем компьютере.
- Сами 1С, Apache и рабочая база не переустанавливаются и не изменяются.

## Рассмотренные варианты

1. **Приватный GitHub — выбран.** Даёт ссылку, историю изменений, обновления и штатное скачивание ZIP.
2. **Отдельный ZIP.** Отклонён как дублирование функции GitHub Download ZIP.
3. **Перенос Codex.** Отклонён, так как на рабочем компьютере уже используется Claude.

## Финальная структура

```text
1c-bread-workspace/
├── CLAUDE.md
├── README.md
├── connector/
├── web/
├── docs/
├── config/
├── scripts/
├── tests/
└── backups/
```

### Назначение

- `CLAUDE.md` задаёт Claude границы, правила работы с 1С и порядок первого запуска.
- `connector/` содержит PowerShell/CMD-соединитель.
- `web/` содержит веб-прототип без пересоздаваемых сборок и зависимостей.
- `docs/` содержит контекст, архитектуру, статус и регламенты.
- `config/` содержит только безопасные шаблоны.
- `scripts/` содержит установку, запуск и проверку.
- `tests/` содержит безопасные проверки без записи в рабочую 1С.
- `backups/` содержит только инструкцию; сами резервные копии игнорируются Git.

## Установка на Windows

1. Проверить версию Windows, права и наличие `winget`.
2. При возможности установить отсутствующие Git и Node.js LTS штатными средствами Windows.
3. При отсутствии `winget` создать отчёт и показать ручные шаги.
4. Выполнить `npm ci` для веб-прототипа.
5. Провести локальные тесты.
6. Открыть папку проекта в Claude и попросить прочитать `CLAUDE.md`.
7. При недоступном терминале Claude запустить `Установить.cmd` вручную.

## Безопасность

- Не переносить `.codex-local`, `.env`, авторизацию, пароли, токены, выгрузки и локальные базы.
- Обычные тесты 1С должны быть только читающими.
- Тестовая запись допускается только в публикацию `khleb1c_test` после проверки пути тестовой базы.
- Любая запись в рабочую 1С без отдельного явного разрешения запрещена.
- Перед упаковкой выполняется поиск вероятных секретов и локальных данных.

## Проверки готовности

- Проверка структуры и обязательных файлов.
- Чистая установка веб-зависимостей через `npm ci`.
- Сборка и тест веб-прототипа.
- Статическая проверка PowerShell-скриптов, где она доступна.
- Проверка на секреты и запрещённые пути.
- Проверка, что клон или GitHub Download ZIP содержит все обязательные файлы.

## Ключевые риски

- В Windows Lite могут отсутствовать Microsoft Store или `winget`.
- Для первичной установки npm-пакетов нужен интернет.
- У Claude может не быть доступа к терминалу; для этого нужен ручной CMD-запуск.
- Неверная публикация 1С может создать риск записи в рабочую базу; это блокируется проверками и правилами Claude.
- Ошибочная публичная публикация может раскрыть бизнес-контекст; репозиторий должен быть приватным.

## Журнал решений

1. Личный WorkHub не переносится.
2. Создаётся отдельный проект `1c-bread-workspace`.
3. Выбран один приватный GitHub-репозиторий; отдельный ZIP не нужен.
4. Claude на целевом компьютере уже установлен; Codex не переносится и не устанавливается.
5. Основная инструкция для AI-ассистента — `CLAUDE.md`.
6. Скрипт сам определяет наличие `winget`, Git, Node.js и прав администратора.
7. Авторизация и секреты не переносятся.
8. Запись в рабочую 1С без отдельного явного разрешения запрещена.

## Критерии готовности

- Новый репозиторий содержит только контур «1С-Хлеб».
- Установка и проверка запускаются понятными Windows-скриптами.
- Claude получает достаточный контекст и ограничения из `CLAUDE.md` и `docs/`.
- Веб-прототип устанавливается и проходит сборку и тесты.
- Репозиторий можно клонировать Git или скачать как ZIP средствами GitHub.
- Приватная публикация GitHub выполняется только после проверки состава и секретов.
