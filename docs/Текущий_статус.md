# Текущий статус «1С-Хлеб»

Дата: 2026-08-17

## Что уже есть

- Мобильный веб-прототип проверки хлебной накладной.
- Локальная OData-публикация 1С по адресу `http://localhost/khleb1c/odata/standard.odata`.
- Безопасные сценарии чтения метаданных, номенклатуры, контрагентов и истории «Мельника».
- Сценарий создания одной непроведённой накладной только в тестовой копии `C:\Baze_Test_Hleb`.
- Защита от дублирования тестового документа по уникальному локальному маркеру.
- Реальные GUID и состав тестовой накладной вынесены в игнорируемый
  `connector/business-data.local.json`; в репозитории остаётся только шаблон.

## Что не готово

- Веб-прототип пока не распознаёт реальные фотографии и не передаёт задания в 1С.
- Нет разрешённой записи в рабочую базу.
- Нет автоматического проведения поступления и подтверждённого обмена с кассой.

## Следующий безопасный шаг

Продолжить сопоставление реальных накладных «Мельника» и «Витязя» с данными 1С в режиме чтения.

## Техническая проверка перед переносом

- Чистая установка `npm ci`, сборка, линтер и два автотеста проходят.
- Аудит рабочих npm-зависимостей: 0 известных уязвимостей.
- В необязательном `drizzle-kit` остаются 4 умеренных проблемы его внутреннего старого `esbuild`;
  npm не предлагает неломающего исправления. Этот инструмент не используется при обычном запуске прототипа.
